A deterministic, stdlib-only program that writes one single-line joke about a meeting that should have been an email to `/output/entry.txt` for make.fun's "The Meeting That Should Have Been an Email" bounty.

The joke: after 45 minutes, the meeting's only decision was to schedule another meeting to figure out what the first meeting was for.

## Run it

```sh
python3 main.py
```
